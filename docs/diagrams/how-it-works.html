How a request to Gemini runs

Claude asks agy-call to do the work; agy-call gives Gemini its own worktree and a grant made for this one job, runs your check after every turn, and hands the result back for Claude to verify and merge. A review takes the same path with a read-only snapshot instead of a worktree and returns a findings list instead of changed files.

A coding task, from request to merge

A job's states

Every task, review and run job moves through these states; agy-call status shows them, and the exit code tells a script which one it ended in. A quota error writes one hold that every other caller on the machine respects until the reset time.
